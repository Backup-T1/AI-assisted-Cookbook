# AI-assisted-Cookbook
This repository showcases my original Gemini AI integration developed as part of a five-person final project for a Human Computer Interaction Course at UC Merced

My contributions included integrating Google's Gemini API with an associated API key, designing a JSON response schema, and testing and debugging generated recipe outputs to meet project requirements.

This version predates the team's final motion-control integration.


Local Setup:

This application uses Google's Gemini API to generate structured recipe information. A valid Google Gemini API key is required to run the AI functionality locally.

Installation - Install the required Python dependencies:

pip install -r requirements.txt


Set the GEMINI_API_KEY environment variable using your own Google Gemini API key.

Run the Flask application:

python app.py

Note: API keys are not included in this repository for security reasons.
